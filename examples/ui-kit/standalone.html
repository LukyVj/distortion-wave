distortion-wave

An API shaped like document.startViewTransition() that plays a WebGL2 wave on any DOM element.

import { distortionWave } from 'distortion-wave';

button.addEventListener('click', (e) => {
  distortionWave(card, () => { /* change the DOM */ }, { source: button, focus: e });
});
  • Click, touch or keyboard: try Tab then Enter
  • Every card below is plain HTML and CSS
  • Zero dependencies, one WebGL2 pass
